SCORING CONTRACT
For each required reference, truth=all labeled target IDs; prediction=its retrieved candidates passing the threshold.
F0.5 = 1.25*TP / (1.25*TP + FP + 0.25*FN).
Both truth and prediction empty -> 1; truth empty with any prediction -> 0.
Average over ALL required references. Require exact prediction coverage and explicit truth coverage; missing rows are errors. An oracle filters candidates with truth ONLY for diagnostic evaluation, never for inference.
